# Python

- It is a high-level, interpreted, dynamic programming language developed by Guido van Rossum.
- It is multi-purpose language not specific for domains like web/app development.
- It uses simple syntax make it suitable for app development.
- Debug cycle wont contain compliation because it is a programming language
- It is dynamic programming language but support programming patterns like object oriented, procedural, functional and impertaive.
- The user dont need to specify the data type while declaring variable because of its dynamic nature.
